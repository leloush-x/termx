# IME Matrix

The implementation uses a normal text-class IME connection with suggestions enabled and personalized learning disabled. Shadow-line state mirrors text committed since the last terminal reset, while Enter, navigation, modifier combinations, paste, and unsupported deletes reset the shadow safely. The matrix below is intentionally unfilled until each keyboard is tested on a physical device.
